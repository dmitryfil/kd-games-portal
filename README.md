# KD Games Portal

Public issue tracker for KD apps and games.

Use this repository's [Issues](https://github.com/dmitryfil/kd-games-portal/issues) to report bugs, request features, ask questions, or share feedback.

## Reporting issues

When creating an issue, include:

- The app or game name
- What happened and what you expected
- Steps to reproduce the issue, if possible
- Your device model, operating system version, and app version
- For Math Trainer exercises: the language, difficulty, and exercise type

For Math Trainer issues, use the `math-trainer` label.

Issues and attachments are public. Do not post personal information, children's identifying details, analytics IDs, or screenshots containing private information. For a privacy request, open a general question asking how to contact the maintainer privately; do not include the underlying personal data.
